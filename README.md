# 漏斗 Funnel

个人收藏消化工具。提供原生微信小程序，以及使用同一份业务逻辑的浏览器预览。

当前版本为本地存储版：首次使用没有预置收藏、好友或统计；不依赖服务器、账号登录、数据库或第三方运行库。

## 在线演示

GitHub Pages 上的版本会预置 20 条**合成演示数据**，方便直接查看队列、到期、已处理和统计界面；数据只写进当前浏览器的 `localStorage`，不会上传，也不代表真实收藏。需要恢复初始演示数据时访问 `/?demo=reset`。

演示构建只用于展示，不进入微信小程序代码包：

```bash
npm run build:demo   # 生成 docs/
```

## 已实现

- 粘贴公众号、小红书、抖音等链接或完整分享文案；识别 `xhslink.com` / `v.douyin.com` 短链接。
- 多条链接、文字段落、JSON 条目数组与本产品 JSON 备份导入；导入前预览，确认后落盘。
- URL 去重；小红书和抖音内容 ID 去重时保留原始链接中的访问参数。
- 收藏理由、3 / 7 / 30 天期限、最多 3 条今日队列、其余存档、到期列表。
- 读完和总结、放走、续期一次、重新预约、永久删除。
- 从真实条目计算读完率、状态统计、来源统计。
- 本地持久化、JSON 备份和合并恢复、隐私与使用帮助、删除确认、保存失败提示。

到期内容不会静默删除。读完率 = 当前已读完数 / 当前全部数；永久删除会更新分母。

## 浏览器预览

```bash
cd funnel-proto
python3 -m http.server 8000 --bind 127.0.0.1
```

访问 http://localhost:8000 。原型服务若已运行，刷新页面即可。

旧演示版存储键 `funnel_proto_v1` 保留，不自动带入新版本；新版本使用 `funnel_real_v1`。旧代码另存于项目外的 `funnel-proto-legacy-20261024-*`，不进入小程序发布包。

## 微信开发者工具

1. 导入整个 `funnel-proto` 目录，工具会读取根目录 `project.config.json`。
2. 当前 `appid` 为微信游客开发配置 `touristappid`，仅供本地导入；上传前必须改成你注册的小程序 AppID。
3. 源码根目录已设置为 `miniprogram/`，原生页面为 WXML / WXSS / JS。
4. 使用真实 AppID 后进行编译、真机预览和备份分享测试。运行库建议选开发者工具当前稳定版本。
5. 按 `RELEASE.md` 完成主体资料、备案、隐私设置和提审。

AppID 是公开项目标识，不要在代码中填写 AppSecret、Cookie 或账号密码。本版不需要这些凭据。

## 导入格式

纯文本支持完整分享文案、每行一个链接，以及 `标题 | https://…`。无链接的文字按空行切分，每段首行作标题，正文保留。多条导入共用你填写的阅读理由。

JSON 支持数组，或 `{ "items": [...] }`。字段为 `title`、`url`、`content`、`reason`；兼容小红书 `note_id` / `noteId` 和 `xsec_token`。自有备份标记 `app: "funnel"`、`version: 1`，恢复时保留处理状态、总结和日期。恢复采用合并去重，不覆盖已有条目；每次文件/文本上限 2 MB，最多保存 1500 条，总备份大小不超过约 900 KB。

浏览器版可选择 JSON 文件；原生小程序可粘贴 JSON 内容恢复。本版本没有读取会话文件权限或自动读取剪贴板。

## 数据边界

浏览器与小程序、不同设备之间不自动同步，可用 JSON 备份迁移。清缓存、卸载或换设备可能丢失本地内容。不要将包含私人内容的备份公开发布。

小程序提供复制原文链接，由用户到来源 App 阅读；网页预览额外提供浏览器打开原文。没有内嵌任意外部网站。未接入微信收藏数据库读取、小红书网页提取或抖音账号收藏同步；本版不宣称有这些能力。

删除了演示好友、虚构排行、随机画像、预置积分/连胜、模拟微信通知、假的分享链接。原先的卡片复习和社交玩法未进入首发版本。

## 检查

```bash
npm test
npm run check
```

Node.js 内置测试，无需安装 npm 依赖。检查业务状态、真实分享文案解析、恶意链接、去重、备份往返、存储失败、原生页面注册与导入确认，以及代码语法、JSON 配置和页面路由。

浏览器空态与批量导入预览已经人工操作验证。本机未安装微信开发者工具，原生 WXML 编译和 iOS / Android 真机验证尚未完成；测试通过不等于微信审核通过。

## 目录

- `miniprogram/`：微信原生应用；上传仅包含这里的文件。
- `miniprogram/lib/core.js`：两端共享的业务逻辑与数据验证。
- `miniprogram/lib/store.js`：微信本地存储和备份导出。
- `static/`、`index.html`：浏览器预览。
- `tests/`、`scripts/`：逻辑测试与项目检查。
- `RELEASE.md`：发布配置、验收和审核说明。
